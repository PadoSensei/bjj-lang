# Contributing

## Workflow
1. Find or create a GitHub issue with clear acceptance criteria.
2. Create a focused branch: `feat/<short-name>`, `fix/<short-name>`, `docs/<short-name>`.
3. Implement only the issue scope.
4. Add/update tests and documentation.
5. Open a pull request using the repository template.
6. Wait for required CI checks and review before merging.

## Commit messages
Use a simple conventional format:
- `feat: add onboarding language selection`
- `fix: prevent duplicate review sync`
- `docs: clarify offline sync contract`
- `test: cover scheduler rating transitions`
- `chore: configure lint workflow`

## Definition of done
See `AGENTS.md`. Never commit secrets or real user data.
