## Detailed Findings & Component Audit

### 1. Design System & Tokens (`src/theme/tokens.ts`)
- **Tokens defined:**
  - `colors`: Background (`#0F172A`), Surface (`#1E293B`), Primary (`#38BDF8`), Secondary (`#818CF8`), Text (`#F8FAFC`, `#94A3B8`, `#64748B`, `#0F172A`), Belts (White `#F8FAFC`, Blue `#2563EB`, Purple `#7C3AED`, Brown `#92400E`, Black `#18181B`).
  - `spacing`: `xs` (4), `sm` (8), `md` (12), `lg` (16), `xl` (24), `xxl` (32), `xxxl` (48).
  - `radii`: `sm` (6), `md` (12), `lg` (16), `full` (9999).
  - `typography`: Font sizes, font weights (`400`, `500`, `600`, `700`), line heights.
- **Verification:** All UI components in `src/components/ui/` import tokens strictly without hardcoding arbitrary magic numbers for colors or radii.

### 2. UI Primitives (`src/components/ui/`)
- **Button:**
  - Standard sizes (`sm`: 36px min height, `md`: 44px min height, `lg`: 52px min height).
  - Touch targets adhere to minimum 44px guidelines for primary interactive sizes (`md` / `lg`).
  - Accessible attributes: `accessibilityRole="button"`, `accessibilityState={{ disabled, busy }}`.
- **Card:**
  - Renders as `View` or `Pressable` when `onPress` is supplied.
  - Applies surface styling and press feedback.
- **BeltBadge:**
  - Displays belt identity and rank bar (red rank bar on black belt).
  - Accessible text label: `accessibilityLabel="Belt milestone: <label>"`.
- **ProgressBar:**
  - Normalizes values between 0 and 1 (or 0 and 100).
  - Accessible attributes: `accessibilityRole="progressbar"`, `accessibilityValue={{ min: 0, max: 100, now }}`.
- **CourseDirectionSelector:**
  - Segmented selector for `pt-BR->en` and `en->pt-BR`.
  - Accessible attributes: `accessibilityRole="button"`, `accessibilityState={{ selected }}`.

### 3. Navigation & Domain Isolation
- **Routes:**
  - `/` (`app/index.tsx`): Overview of active course with unit cards and lesson lists.
  - `/select-direction` (`app/select-direction.tsx`): Modal route for course direction selection.
  - `/lesson/[id]` (`app/lesson/[id].tsx`): Dynamic lesson route placeholder.
- **State & Data Separation:**
  - `CourseContext` maintains `direction` state.
  - `MOCK_COURSES` in `src/data/mockCourseData.ts` holds domain data separately from UI components.
