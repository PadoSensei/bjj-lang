# ADR-006: Monetization

- **Status:** Needs confirmation
- **Decision under consideration:** One-time purchase grants permanent access to the English → Brazilian Portuguese course; Portuguese → English remains free; donations are separate.
- **Context:** Both markets from launch and social-impact mission.
- **Alternatives:** Subscription, freemium, academy licenses.
- **Rationale:** Simple user proposition.
- **Consequences:** Define lifetime scope, store policy compliance, refunds/restores, donation recipient/accounting, and regional availability before implementation. Do not promise future courses by implication.
