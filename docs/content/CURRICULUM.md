# Curriculum

## Content principles
- Authentic Brazilian Portuguese (`pt-BR`) and clear English.
- Prioritize language heard in real academies.
- Distinguish literal translation from natural usage.
- Include context and register where necessary.
- Have bilingual/BJJ-aware human review before publication.
- Never publish AI-drafted language without editorial verification.
- Provide audio where possible; document speaker/source rights.
- Track source, reviewer, and revision status for content.

## Initial scaffold
1. Greetings and introductions.
2. Numbers and basic responses.
3. Essential training commands and safety communication.
4. Basic positions and movement vocabulary.
5. Asking for clarification and describing techniques.
6. Short contextual dialogues.
7. Introductory BJJ history and culture reading.

## Belt-inspired app progression
White: basic words/phrases.
Blue: understand common instructions.
Purple: communicate about positions and techniques.
Brown: longer instructions and tactical language.
Black: reading, culture, history, nuanced discussion.

These labels indicate language learning progress only, never actual martial arts rank.

## Content data
Use stable concept keys and structured language-tagged translations. Lessons reference concept IDs; content is not embedded in screen components.
