# ADR-001: Mobile Framework

- **Status:** Proposed
- **Decision:** Expo + React Native + TypeScript, with Expo Router.
- **Context:** Solo developer, five-week delivery target, iOS and Android requirements, AI-assisted coding.
- **Alternatives:** Native Swift/Kotlin, Flutter, PWA-first.
- **Rationale:** Shared code across platforms, rapid iteration, managed build ecosystem, TypeScript continuity.
- **Consequences:** Must validate required native modules and store requirements early; native build/release still needs platform QA.
